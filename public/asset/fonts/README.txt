Download these font files from Google Fonts and place them here:
1. Go to: https://gwfh.mranftl.com/fonts/sarabun?subsets=latin,thai
2. Select weights: 300, 400, 600, 700
3. Download and extract all .woff2 files to this folder
4. Files needed:
   - sarabun-v15-latin_thai-300.woff2
   - sarabun-v15-latin_thai-regular.woff2
   - sarabun-v15-latin_thai-600.woff2
   - sarabun-v15-latin_thai-700.woff2
